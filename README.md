# StandbyOBS

フォートナイトを起動したら、OBS を自動で準備する Windows のタスクトレイ常駐ツールです。

- OBS が起動していなければ、起動する
- OBS を決めたプロファイル・シーンコレクション・シーンに切り替える
- リプレイバッファを開始する（フォートナイトを閉じたら止める）

「OBS の起動を忘れて、いいところを撮り逃した」を防ぐためのツールです。
クリップの保存はしません。保存は OBS の「リプレイバッファを保存」のホットキーなどで行ってください。
待機中の負荷はとても小さく、メモリ約 11 MB、CPU はほぼ 0% です（作者の PC で測定）。

> 非公式のツールです。Epic Games・OBS Project とは関係ありません。

## ダウンロード
[Releases](https://github.com/froshoulder/StandbyOBS/releases) から `StandbyOBS-1.0.0.zip` をダウンロードしてください。

## 動作環境
- Windows 11（64 ビット）
- OBS Studio 28 以降（WebSocket が入っているもの）。OBS 32.2.2 で確かめました。

## 使い方（かんたん）
1. OBS で次の 2 つを ON にする
   - 「ツール → WebSocket サーバー設定」の「WebSocket サーバーを有効にする」
   - 「設定 → 出力 → リプレイバッファ」の「リプレイバッファを有効にする」
2. ZIP を展開して、フォルダを自分のフォルダ（ドキュメントなど）に置く
   （`C:\Program Files` の下には置かないでください）
3. `StandbyOBS.exe` を起動して、設定の画面で OBS のプロファイルやシーンを選ぶ
4. あとはフォートナイトを起動するだけ

初めて起動すると「Windows によって PC が保護されました」と出ることがあります。
電子署名を付けていないためで、「詳細情報」→「実行」で起動できます。

くわしい使い方は、ZIP の中の `README.txt` を見てください。
